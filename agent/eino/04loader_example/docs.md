# Document Loader

接下来的内容是和 RAG 相关的内容。

如果你要准备一个知识库，思考一下准备流程是什么。

准备数据、检索数据、使用数据。

用户问题 + 知识库资料 ---> llm ---> 回答

面临痛点：真实业务场景中的资料或知识库多达几万条，大模型的上下文是有限的，就算有超长上下文，其注意力也是有限的。基于这种现状，如何从工程方面完善这种能力？

用户的问题 + 与问题相关的知识 ——> LLM ——> 回答

RAG 由此产生。

准备数据 ——> 检索数据 ——> 使用数据

Loader ----> Transformer（拆分数据） ----> Embedding ----> Indexer（存储）----> Retriever（查询）

```
遇事不决写注释
1. 初始化 Loader
2. 加载文档
3. 打印验证
```

注意，`go mod tidy` 后会自动下载 0.6 版本的 eino，需要用 `go get` 下载最新版本。

```
go get github.com/cloudwego/eino@latest
```
